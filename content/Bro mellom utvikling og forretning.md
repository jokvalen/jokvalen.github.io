Jeg ser begge sider. Med bakgrunn som [[Webutvikling|webutvikler]] og webredaktør forstår jeg hvordan ting bygges, og etter mange år med analyse og CRO forstår jeg hva markeds- og forretningssiden trenger. Derfor blir jeg ofte oversetteren mellom dem.

- **Telekom** ([[Kundeprosjekter|kundeoppdrag]]): oversatte forretningens innsiktsbehov til konkrete krav om hva som skal spores og hvordan, på tvers av web og app.
- Sporingsplaner og e-handels-dataLayer som utviklere kan implementere og markedssiden kan bruke ([[Digital analyse og måling]]).
- Prosjektleder for [[Ny onecall.no]], og samarbeid mellom interne og eksterne designere og utviklere på [[Responsiv onecall.no]].
- [[Fra e-post til dokumenthåndtering]]: oversatte mellom utvikler- og brukerspråk.
- Backlog og brukerbehov for [[OneCall-appen]].
- A/B-tester fra hypotese til implementering og beslutning ([[CRO og eksperimentering]]).
